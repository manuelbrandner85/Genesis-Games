# GENESIS GODMODE 4.1 – Einfach anfangen

**Ein ZIP = Entwicklungsauftrag, NICHT das bereits fertige Spiel und NICHT vorinstallierte KI-Gewichte.**

1. Dieses komplette ZIP auf deinem Windows-PC entpacken, z.B. `C:\GENESIS-GODMODE-4.1-PAKET`.
2. **Claude Code in genau diesem entpackten Paketordner starten** (nicht im alten Repo).
3. Gib Claude Code diesen ersten Auftrag (kopieren):

> Lies `CLAUDE.md`, `GENESIS_CLAUDE_CODE_MASTERPROMPT_V4_1.md` und `START_HIER_V4_1.md` vollständig. Beginne mit der reinen Bestandsaufnahme F0/G0; prüfe meine Hardware, meine vorhandenen KIs, Blender, Unreal Engine 5 und sämtliche Original-GENESIS-Quellen. Gib mir danach eine deutschsprachige Freigabeliste für kostenlose Bild-, 3D-, Musik-, Stimmen- und Transkriptions-Tools. Keine Downloads, Installationen, Zahlungen, Änderungen am alten GENESIS-Repository oder neue endgültige Storyinhalte ohne meine ausdrückliche Einzelfreigabe. Danach richte das NEUE GENESIS-Projekt getrennt vom alten ein und baue zunächst die Goldstandard-Spielregion bis zur realen Unreal-Abnahme. Baue anschließend nach dem freigegebenen Produktionsplan das vollständige Spiel weiter.

4. Nach Inventur und deiner **gesonderten Freigabe**: neues Projekt mit `python tools/v4/init_new_game.py --target "C:\Games\GENESIS-NEW" --engine-association <GEPRUEFTE_UE_VERSION> --apply` (erst ohne `--apply` ausprobieren). Der Zielordner darf noch NICHT existieren.
5. Claude soll vor dem Installieren konkrete Versions-/Gewichts- und Lizenznachweise liefern; bezahlte Cloudnutzung ist standardmäßig verboten.
6. Gib Claude die originalen Storybibel-/Drehbuch-Dateien und die GENESIS-Jenseitsvorgaben, wenn sie nicht in der Übergabe liegen. Das ZIP enthält sie NICHT vollständig.
7. Öffne danach Claude Code im **neu erzeugten** Spielprojektordner; dort geht die Produktion weiter. Danach Blender/Unreal wirklich starten und Ergebnisse prüfen lassen.

**Relevante Dateien:** `GENESIS_CLAUDE_CODE_MASTERPROMPT_V4_1.md`, `docs/v4_1/FREE_AI_TOOL_MATRIX.md`, `docs/v4_1/FREE_AI_PRODUCTION_PIPELINES.md`, `.claude/skills/genesis-free-ai-preflight/SKILL.md`.
