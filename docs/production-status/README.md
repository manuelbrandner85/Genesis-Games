# Ehrlicher Statusfeed

Hier liegen aktuell **keine echten Runtime-Workorders**. Nur lokal und nach tatsächlichen Tests erzeugte Jobstatus-JSON-Dateien hinzufügen. `tools/qa/render_status.py` stellt aus ihnen eine statische HTML-Snapshotseite dar. Keine fiktiven Fortschrittsprozente, Liveagenten oder gemessene FPS.
